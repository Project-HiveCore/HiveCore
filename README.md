# HiveCore

A 32-bit RISC-V, out-of-order, superscalar CPU core.

## Directories

```
.
├── arch
│   ├── isa 	# ISA documentation
│   └── spec	# Architecture speficiations
│
├── core
│   ├── <module>
│   │   ├── sim	    # Testbenches and verification scripts
│   │   ├── spec    # Module specifications
│   │   └── src     # Module code
│   └── pkg
│
└── tpl	   # Templates
```
